# AKN Setlist 🎵

AKN Setlist is a native Android application built for independent artist AKN, providing a clean and convenient way to browse songs, search the setlist, and view lyrics and chords during live performances.

Developed using Java and XML in Android Studio, the app integrates with Supabase to synchronize the latest active songs while maintaining a local SQLite cache for offline access. Its dark, minimalist interface focuses on readability, smooth navigation, and a premium music-focused experience.

**Tech Stack:** Java, XML, Android SDK, SQLite, Supabase REST API, AndroidX RecyclerView.
